3 · Upgrade existing Mermaid blocks

run() finds pre.mermaid and Markdown's ```mermaid blocks and renders them with their layout blocks. Per-block options go in data attributes.

stateDiagram-v2
  [*] --> Draft
  Draft --> Review : open PR
  Review --> Draft : changes requested
  Review --> Live : approved
  Live --> [*]

%% @layout v1
%% Live  nudge 120,0
%% @end
<pre class="mermaid" data-theme="mermaid">stateDiagram-v2 …</pre>

import mermaid from 'mermaid';
import { defineWermaidElement, run } from 'wermaid/element';
defineWermaidElement(mermaid);
run();

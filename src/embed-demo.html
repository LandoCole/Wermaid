3 · Upgrade existing Mermaid blocks

run() finds pre.mermaid and Markdown's ```mermaid blocks and renders them with their layout blocks. Per-block options go in data attributes.

stateDiagram-v2
  [*] --> Draft
  Draft --> Review : open PR
  Review --> Draft : changes requested
  Review --> Live : approved
  Live --> [*]

%% @layout v1
%% Live  nudge 120,0
%% @end
<pre class="mermaid" data-theme="mermaid">stateDiagram-v2 …</pre>

import mermaid from 'https://cdn.jsdelivr.net/npm/mermaid@11.16.1/dist/mermaid.esm.min.mjs';
import { defineWermaidElement, run } from 'https://cdn.jsdelivr.net/gh/LandoCole/Wermaid@v0.4.0/src/element.js';
defineWermaidElement(mermaid);
run();

4 · Features

features lists what the viewer offers. This one is editable: drag shapes, Alt-drag to pin, resize from the corners, drag a line to bend it, arrow keys to nudge. Undo and Reset come with edit, and themes adds a theme picker. Your adjustments are kept in this browser and come back on reload; Reset forgets them.

5 · Your own theme

defineTheme registers a theme from plain data. It works by name in theme, in %% @theme and in the picker above, and its dark variant is derived from the light colours. The editor's Theme button builds one of these on a real diagram and copies the code.

flowchart TD idea([Idea]) --> draft[Draft] draft --> review{Review} review -->|changes| draft review -->|approved| ship[Ship] 
defineTheme('acme', {
  label: 'Acme',
  colors: { background: '#fffaf0', text: '#3a2406', line: '#8a5a1c',
            nodeFill: '#ffe9c2', nodeBorder: '#d98324' },
  shapes: { radius: 8, borderWidth: 1.5 },
  edges: { style: 'rounded', radius: 8, width: 1.5 },
});
